# Scientific Correctness, Mathematical Rigor & State Preservation Invariants

## 1. Guiding Axioms of SeeDL

In scientific computing and AI research, a visualization library must act as an objective measurement tool. An instrument that mutates the system under observation, fabricates unmeasured signals, or produces misleading mathematical approximations ceases to be scientific.

SeeDL is engineered around **four core scientific commitments**:

1. **Non-Invasive Observation**: Observing a model must never alter its operational behavior, training state, parameter values, or gradient history.
2. **Empirical Authenticity**: Visualizations depict only verifiable numerical data. No fake execution graphs, no fabricated attention paths, no synthetic quantum fidelities.
3. **Mathematical Precision**: Algorithms adhere strictly to published literature formulas with verifiable error metrics.
4. **Offline Reproducibility**: Visualizations and analysis artifacts must be fully self-contained and reproducible without network connectivity.

## 2. Invariant Specifications

### A. Autograd State Preservation
Whenever SeeDL inspects a PyTorch model (`sd.trace`, `sd.flow`, `sd.explain`, `sd.gradient_health`):

```python
# Exact pattern enforced across all SeeDL internal modules:
states = [(m, bool(m.training)) for _, m in model.named_modules()]
saved_grads = {
    name: param.grad.clone() if param.grad is not None else None
    for name, param in model.named_parameters()
}
try:
    model.eval()
    # Perform isolated inspection pass ...
finally:
    # 1. Restore original training modes
    for m, training in states:
        m.training = training
    # 2. Restore exact parameter gradients
    for name, param in model.named_parameters():
        if saved_grads.get(name) is not None:
            param.grad = saved_grads[name]
        else:
            param.grad = None
    # 3. Guaranteed hook removal
    for h in registered_hooks:
        h.remove()
```

### B. Hook Cleanup Guarantee
- All PyTorch forward and backward hooks are registered inside a `try` block.
- Hook removal is placed in the `finally` block to guarantee execution even when exceptions, OOM errors, or assertion failures occur.
- No dangling hooks remain to degrade subsequent training steps.

### C. Gradient Health & Tied Parameter Deduplication
In models with weight tying (e.g. embedding and LM head sharing identical weight tensors):
- Conventional parameter iteration overcounts parameters and inflates global gradient norms.
- SeeDL tracks parameter tensor memory addresses (`param.data_ptr()`). Tied parameters are clearly flagged (`is_tied=True`) and deduplicated when computing the global gradient $L_2$ norm:
  $$\|\nabla W\|_{\text{global}, 2} = \sqrt{\sum_{p \in \text{Unique}} \|\nabla W_p\|_2^2}$$

### D. Quantum CPTP Channel Completeness
For any open quantum system simulation with Kraus operators $\{K_k\}$:
1. **Kraus Completeness Relation**:
   $$\sum_k K_k^\dagger K_k = I$$
   Verified numerically within machine precision ($\epsilon < 10^{-7}$).
2. **Trace Preservation**:
   $$\text{Tr}(\rho') = \text{Tr}\left(\sum_k K_k \rho K_k^\dagger\right) = 1.0$$
3. **Hermiticity**:
   $$\rho' = (\rho')^\dagger$$

## 3. Disclaimers & Explanatory Boundaries

Every scientific visualization generated by SeeDL includes clear, contextual explanatory notes:
- **Saliency vs Causality**: Gradient saliency measures local sensitivity at the input; it does not constitute a proof of causal mechanism.
- **Rollout vs Non-Linearity**: Attention rollout tracks query-key routing; downstream non-linear activations and MLP transformations can modify representations independently.
- **GPU Asynchronous Overhead**: Latency measurements on CUDA devices reflect asynchronous kernel launches unless explicit synchronization (`torch.cuda.synchronize()`) is active.
