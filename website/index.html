08 / YOUR FIRST VIEW

Bring your own model.

Pass your PyTorch model and sample input. SeeDL traces execution, tracks tensor shapes, and renders interactive graphs.

Execution runs locally in Python with zero cloud calls. All exports are self-contained HTML.

Read the Quickstart →
observatory_quickstart.py
import torch
from torch import nn
import seedl as sd

model = nn.Sequential(
    nn.Linear(4, 8), nn.ReLU(), nn.Linear(8, 2)
)
x = torch.randn(1, 4)

# 1. Trace execution flow
flow = sd.flow(model, x, mode="graph")
flow.save("flow.html")

# 2. Check gradient health
loss = model(x).sum()
loss.backward()
health = sd.gradient_health(model)
health.save("gradients.html")
