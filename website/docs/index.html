See what you're building.

From your first visualization to neural execution tracer DAGs, tensor flow pipelines, Transformer attention rollout, attribution benchmarks, gradient telemetry, and open quantum systems. These examples use the published SeeDL 0.5.0 API.

Getting Started

SeeDL turns supported Python objects into inspectable scientific visualizations. The core has no required third-party dependencies and includes an SVG renderer and self-contained offline HTML exporters. Plotly adds interactive 3D and comparison charts; PyTorch and Qiskit provide their respective integrations. Python 3.10 or newer is required.

Installation

Core · no required dependencies
pip install seedl==0.5.0
Vision, Tracing & 3D · PyTorch + Plotly
pip install "seedl[torch,plotly]==0.5.0"
Quantum · Qiskit + Plotly
pip install "seedl[quantum,plotly]==0.5.0"
All integrations
pip install "seedl[all]==0.5.0"

Quickstart

Start with a numeric sequence. This example works with the core installation alone.

import seedl as sd

view = sd.see([1, 4, 2, 8], backend="svg")
view.save("first.svg")
view.save("first.html")

In a notebook, put view last in a cell to display it. In a Python script, use view.show(). view.figure returns the backend figure (or SVG text), and view.data contains the inspected data.

Neural Execution Tracing

Inspect the forward pass execution topology of supported PyTorch models. sd.flow(model, input, mode="graph") records observed module execution and generates an interactive DAG depicting operation nodes, tensor shapes, execution order, parameter counts, and explicit tensor dependencies (including residual skip branches and in-place aliases). Tensor dependencies are inferred from recorded module inputs and outputs rather than static AST parsing; models with complex dynamic control flow, custom forward methods, or functional operations outside standard modules may exhibit tracing limitations. In addition, model forward execution invokes standard Python code and does not sandbox arbitrary Python side effects.

import torch
from torch import nn
import seedl as sd

model = nn.Sequential(nn.Linear(4, 6), nn.ReLU(), nn.Linear(6, 2))
x = torch.randn(1, 4)
trace_view = sd.flow(model, x, mode="graph")
trace_view.save("trace.html")

Transformer Attention Explorer

Inspect empirical query-key routing probabilities, multi-head alignment, and token-level interaction. Captures per-head weights from torch.nn.MultiheadAttention or raw attention weight tensors.

import torch
from torch import nn
import seedl as sd

mha = nn.MultiheadAttention(embed_dim=16, num_heads=4, batch_first=True)
tokens = ["The", "model", "attends", "to", "tokens"]
x = torch.randn(1, len(tokens), 16)
output, weights = mha(x, x, x, need_weights=True, average_attn_weights=False)
view = sd.attention(weights, tokens=tokens)
view.save("attention.html")

Attention visualizations display observed routing weights P(K_j | Q_i), not causal explanations of model decisions. Values form a valid probability distribution where rows sum to ~1.0 with non-negative weights.

Attention Rollout

Compute cumulative attention propagation across multi-layer Transformers. Evaluates residual attention accumulation: A'_l = 0.5 × (A_l + I), with cumulative product R = A'_L @ A'_(L-1) @ ... @ A'_1.

import torch
import seedl as sd

tokens = ["[CLS]", "Neural", "Observatory", "[SEP]"]
layers = [torch.softmax(torch.randn(1, 2, 4, 4), dim=-1) for _ in range(2)]
rollout_view = sd.attention_rollout(layers, tokens=tokens, include_residual=True)
rollout_view.save("rollout.html")

Attribution Benchmark Lab

Benchmark feature attribution algorithms side-by-side on the exact same model and input. Evaluates Saliency Maps, Integrated Gradients (using composite midpoint numerical integration), and SmoothGrad (Gaussian noise variance reduction). Gradient Health Diagnostics

Inspect layer-level and parameter-level gradient telemetry directly from existing autograd buffers. Evaluates L1/L2 gradient norms, gradient-to-weight magnitude ratios, exact zero-gradient fractions, and nonfinite (NaN/Inf) occurrences. Zero-gradient fractions are observational diagnostics rather than universal diagnoses of dead neurons: zero gradients routinely occur for multiple reasons, including sparse inputs, unused or frozen parameters, activation saturation, ReLU deactivation, and disconnected computational paths. Gradient-health warnings flag potential vanishing, exploding, or stalled regions for empirical review.

import torch
from torch import nn
import seedl as sd

model = nn.Sequential(nn.Linear(4, 8), nn.ReLU(), nn.Linear(8, 2))
loss = model(torch.randn(2, 4)).sum()
loss.backward()
grad_view = sd.gradient_health(model)
grad_view.save("gradient_health.html")

SeeDL Training Recording

Record bounded, immutable training passes. Capture after loss.backward() and before optimizer.step(), while parameters and gradients still match the forward pass.

import torch
from torch import nn
import seedl as sd

torch.manual_seed(41)
model = nn.Sequential(nn.Linear(2, 4), nn.Tanh(), nn.Linear(4, 1))
x = torch.tensor([[1.0, -2.0]])
optimizer = torch.optim.SGD(model.parameters(), lr=0.08)
with sd.watch(model, name="Regression", max_snapshots=4) as run:
    for step in range(4):
        optimizer.zero_grad(set_to_none=True)
        output = model(x)
        loss = (output - 0.5).square().mean()
        loss.backward()
        run.capture(step=step, epoch=0, loss=loss)
        optimizer.step()
run.playback(backend="plotly").save("training.html")

Step Comparison

sd.compare(snapshot_a, snapshot_b) aligns parameter names, shapes, and sample indices, then reports differences, activation samples, gradient statistics, and output shifts.

import torch
from torch import nn
import seedl as sd

model = nn.Sequential(nn.Linear(2, 4), nn.Tanh(), nn.Linear(4, 1))
x = torch.tensor([[1.0, -2.0]])
with sd.watch(model, name="Regression", max_snapshots=2) as run:
    for s in range(2):
        loss = (model(x) - 0.5).square().mean()
        loss.backward()
        run.capture(step=s, epoch=0, loss=loss)
cmp = sd.compare(run.snapshots[0], run.snapshots[1], names=("Initial", "Updated"), backend="plotly")
cmp.save("comparison.html")

Training Run Comparison

sd.compare_runs(run_a, run_b) compares entire training run histories and experiment trajectories across optimizers or hyperparameters with step alignment and convergence delta analysis. The playground demonstration records authentic training metrics from identical models initialized with the same weights on a small synthetic CPU demonstration (relative performance varies with architecture, hyperparameters, and task; neither optimizer is universally superior).

import seedl as sd

run_a = {"loss": [0.7151, 0.6850, 0.6596, 0.6378], "accuracy": [0.5312, 0.5625, 0.6250, 0.6562]}
run_b = {"loss": [0.7151, 0.6094, 0.5262, 0.4498], "accuracy": [0.7188, 0.7500, 0.7812, 0.9062]}
runs_view = sd.compare_runs(run_a, run_b, name_a="Baseline SGD", name_b="AdamW Optimizer")
runs_view.save("runs.html")

Analysis Serialization & Integrity

Persist and reload SeeDL analysis artifacts securely. sd.save_analysis() writes a deterministic canonical JSON payload with SHA-256 integrity hash verification on load, without Python pickle.

import seedl as sd

view = sd.bloch("+", backend="plotly")
sd.save_analysis(view, "analysis.json")
loaded = sd.load_analysis("analysis.json")

API Reference

Visualization functions return a Visualization; sd.watch returns a training tracker. For complete signatures and implementation details, see the 0.5.0 API source and Visualization reference.

Entry pointPurpose / key options
sd.flow(model, input, mode="graph")Neural execution tracer DAG: observed module execution, explicit tensor edges, in-place aliases, shapes (supported models).
sd.flow(model, input, mode="table")Tensor flow pipeline: layer transitions, memory footprints, activation stats (supported models).
sd.attention(weights, tokens=...)Transformer attention matrix, per-head routing, query distributions.
sd.attention_rollout(layers, tokens=...)Cumulative attention rollout across Transformer layers with residual normalization.
sd.vit_attention(weights, patch_grid=...)Reshape 1D token attention vectors to 2D spatial image patch grids.
sd.compare_attributions(model, input, ...)Attribution benchmark: Saliency vs Integrated Gradients vs SmoothGrad.
sd.gradient_health(model)Gradient diagnostics: L1/L2 norms, gradient-to-weight ratios, sparsity.
sd.watch(model, **limits)Observe training; capture after backward and before optimizer.step().
run.capture(step=..., epoch=..., loss=...)Record completed pass. Metadata is passed by keyword.
run.playback(backend="plotly")Recorded training controls, neuron inspection, loss timeline.
sd.compare(snapshot_a, snapshot_b)Compare aligned captured parameter/output samples and gradient stats.
sd.compare_runs(run_a, run_b)Compare entire training histories across runs with step alignment.
sd.quantum_noise(channel=..., param=...)Open quantum systems: Depolarizing, Amplitude Damping, Phase Damping Kraus noise.
sd.dataset_drift(reference, comparison)Dataset distribution drift: Population Stability Index and Jensen-Shannon Divergence.
sd.report(title, ...)Self-contained offline scientific report compiling multiple SeeDL views.
sd.save_analysis / sd.load_analysisDeterministic canonical JSON serialization with SHA-256 integrity verification.
sd.see(obj, **options)Automatic inspection. input, backend, view, theme, max_neurons, max_connections.
sd.bloch(state, **options)Single-qubit state. view="3d", theme, backend.
sd.circuit(qc, simulate=True)Bounded gate evolution and before/after quantum states.
view.save(filepath)Export HTML, SVG, or PNG; raster exports may require additional backend tooling.
view.to_figure(backend=None)Return the selected backend figure or SVG text.
view.data / view.metadataInspected data and visualization metadata.
