import torch
from torch import nn
import seedl as sd

torch.manual_seed(20)
model = nn.Sequential(
    nn.Linear(3, 5), nn.ReLU(), nn.Linear(5, 3),
    nn.ReLU(), nn.Linear(3, 2),
).eval()
x = torch.tensor([[0.8, -0.4, 0.6]])
view = sd.see(model, input=x, view="3d", theme="scientific")
view.save("network.html")

Hover over gates to inspect · Qiskit ordering: |q₁q₀⟩

Prepare a Bell pair

1. Start at |00⟩
Both qubits begin in zero.

2. Apply H to q₀
Creates (|00⟩ + |01⟩)/√2.

3. Apply CX(q₀, q₁)
Flips q₁ when q₀ = 1.

Final state

|Φ⁺⟩ = (|00⟩ + |11⟩)/√2

Measurement gives 00 or 11 with 50% probability each. Each qubit's reduced state is I/2, with entropy 1 bit.
