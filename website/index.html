04 / A SMALL API, A CLEARER PICTURE

Your model.
A new point of view.

Pass your PyTorch model and a sample input. SeeDL captures a forward pass and renders authentic feature maps or 3D parameter connections.

3D and advanced interactive rendering require the torch and plotly extras. Execution runs locally in Python.

Read the 3D guide →
quickstart.py
import torch
from torch import nn
import seedl as sd

model = nn.Sequential(
    nn.Linear(3, 5), nn.ReLU(), nn.Linear(5, 2)
)
x = torch.tensor([[0.8, -0.4, 0.6]])

view = sd.see(model, input=x, view="3d")
view.save("network.html")
