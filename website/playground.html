Training Playback

Sixteen real forward/backward passes through a 2 → 4 → 1 PyTorch network. Play, pause, rewind, choose a step, or inspect a neuron. The loss chart, weights, activations, and existing gradients come from each captured pass. Live playback means recorded snapshots, not continuous training streamed from a server.

Recorded by SeeDL 0.4.0 · All interaction stays in your browser · On narrow screens, scroll plots sideways
View the Python source
import torch
from torch import nn
import seedl as sd

torch.manual_seed(41)
model = nn.Sequential(nn.Linear(2, 4), nn.Tanh(), nn.Linear(4, 1))
x = torch.tensor([[1.0, -2.0]])
optimizer = torch.optim.SGD(model.parameters(), lr=0.08)
with sd.watch(model, name="Tiny regression", max_snapshots=16,
              max_bytes=512_000, max_values=12,
              max_neurons=12, max_connections=16) as run:
    for step in range(16):
        optimizer.zero_grad(set_to_none=True)
        output = model(x)
        loss = (output - 0.5).square().mean()
        loss.backward()
        run.capture(step=step, epoch=step // 4, loss=loss)
        optimizer.step()  # Always AFTER capture.

snapshot = run.snapshots[0]
print(snapshot.data["loss"], snapshot.data["parameters"])
run.playback(backend="plotly").save("training.html")

Prepare a Bell pair

1. Start at |00⟩
Both qubits begin in zero.

2. Apply H to q₀
Creates (|00⟩ + |01⟩)/√2.

3. Apply CX(q₀, q₁)
Flips q₁ when q₀ = 1.

Final state

|Φ⁺⟩ = (|00⟩ + |11⟩)/√2

Measurement gives 00 or 11 with 50% probability each. Each qubit's reduced state is I/2, with entropy 1 bit.

Quantum Evolution

Select a gate in the diagram or timeline. Compare states before and after H and CX, including reduced-qubit Bloch vectors, basis probabilities, and amplitude phases. All states are checked against Qiskit. At the Bell state each local Bloch vector is zero; the joint state is still pure.

Qiskit basis order: |q₁q₀⟩. Phases of zero-amplitude basis states are undefined. These demos contain only unitary gates. Measurement, reset, conditional, or unsupported operations halt SeeDL evolution; post-halt states are unavailable.
