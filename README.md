## ✨ Why SeeDL?

Most visualization tools tell you **how many parameters** a network has. SeeDL helps you see **what's connected, what it's doing, and why its outputs look the way they do**.

| **Understand** | **Explore** | **Explain** |
| :--- | :--- | :--- |
| See actual MLP neurons, layers and signed weights | Rotate 3D networks, select neurons and step through captured data | Inspect gradients, activations, attention and feature attributions |
| **Learn** | **Track** | **Share** |
| Visualize deep learning concepts interactively | Compare training runs, losses and prediction behavior | Export SVGs, PNGs and self-contained interactive HTML |

### See your first neural network

```python
import torch
from torch import nn
import seedl as sd

model = nn.Sequential(
    nn.Linear(4, 8),
    nn.ReLU(),
    nn.Linear(8, 6),
    nn.ReLU(),
    nn.Linear(6, 2),
)

x = torch.tensor([[0.3, 0.8, -0.2, 1.0]])

sd.see(model)                               # Recognizable 4 → 8 → 6 → 2 diagram
sd.see(model, view="3d")                    # Interactive 3D neurons and connections
sd.see(model, input=x, theme="dark")        # Color neurons by real activations
sd.see(model, input=x).explore()            # Inspect the recorded forward pass
```

**Inspect a particular neuron:**

```python
view = sd.see(model, input=x, select_neuron=(1, 2), view="3d")
view.save("network.html")                  # Standalone interactive HTML
```

Selected neurons highlight incoming and outgoing connections. Inspected values include weights, biases, and captured activations; missing data is shown as unavailable, not zero.

## 🧩 Features

| Capability | What you see | Start with |
| :--- | :--- | :--- |
| **Neural networks · 2D & 3D** | Actual neurons, weights, activations and selection for supported MLPs | `sd.see(model)` |
| **Forward explorer** | Layer controls and playback over recorded computation states | `sd.see(model, input=x).explore()` |
| **Model architecture** | CNN operation blocks and honest module hierarchies | `sd.see(model, view="architecture")` |
| **Tensors & images** | Statistics, heatmaps, image and channel previews | `sd.see(tensor)` |
| **Training & comparison** | Metric curves, smoothing and heuristic diagnostics | `sd.watch()` · `sd.compare()` |
| **Activations & gradients** | Layer responses and gradient health | `sd.activations()` · `sd.gradients()` |
| **Explainability** | Saliency, Integrated Gradients and Grad-CAM | `sd.explain()` |
| **Attention** | Query/key token and multi-head attention heatmaps | `sd.attention()` |
| **Embeddings** | 2D/3D PCA, cosine similarity and category labels | `sd.embeddings()` |
| **Loss landscape** | Bounded 3D surface over two chosen parameter coordinates | `sd.loss_landscape()` |
| **Predictions & datasets** | Classification, residuals and dataset previews | `sd.predictions()` · `sd.dataset()` |
| **Learning** | Visual simulations of core ML mechanisms | `sd.learn()` |
| **Export** | SVG, PNG, self-contained HTML and backend figures | `view.save()` |

### A visualization you can actually inspect

- **Weights, not guesses.** For `nn.Linear`, edges use the real `weight[output, input]` entries and encode sign and magnitude.
- **Activations, not decoration.** With `input=x`, supported networks show data from a captured forward pass for the selected batch sample.
- **Meaningful selection.** Pick an individual neuron for incoming/outgoing connections, layer identity, bias and available activations or gradients.
- **3D is real.** Supported networks use Plotly `Scatter3d` points and lines with a controllable camera, not a 2D image pretending to be 3D.
- **Honest fallbacks.** CNNs use operation blocks; complex custom/residual/transformer models use module hierarchies when exact execution wiring is unavailable.

<details>
<summary><b>Training progress and experiment comparison</b></summary>

```python
tracker = sd.watch(name="experiment_a")
tracker.log(epoch=1, loss=0.84, accuracy=0.63)
tracker.log(epoch=2, loss=0.61, accuracy=0.75)
sd.see(tracker)

sd.compare(
    {"epoch": [1, 2], "loss": [0.9, 0.7]},
    {"epoch": [1, 2], "loss": [0.8, 0.5]},
    names=("Baseline", "New model"),
)
```

</details>

<details>
<summary><b>Attention, predictions and explanations</b></summary>

```python
sd.attention(
    [[0.8, 0.2], [0.3, 0.7]],
    tokens=["Deep", "learning"],
)

sd.predictions(
    [2.4, 0.3, -1.1],
    labels=["cat", "dog", "bird"],
    task="classification",
)

# For an appropriate differentiable model and input:
sd.explain(model, input=x, method="saliency")
sd.explain(model, input=x, method="integrated_gradients", steps=25)
```

</details>

<details>
<summary><b>3D embeddings and loss-coordinate surfaces</b></summary>

```python
import torch
from torch import nn

vectors = torch.randn(32, 6)
sd.embeddings(vectors, dimensions=3)

regressor = nn.Linear(1, 1)
features = torch.linspace(-1, 1, 20).reshape(-1, 1)
targets = 2 * features + 0.5

sd.loss_landscape(
    regressor,
    (features, targets),
    loss_fn=nn.functional.mse_loss,
    axes=(("weight", 0), ("bias", 0)),
    radius=1.5,
    steps=15,
    evaluate=True,  # Explicitly permit repeated loss evaluations
)
```

Loss landscapes depict a **two-coordinate slice**, not the complete high-dimensional loss function. The original model remains separate from the evaluated copy.

</details>

## 📦 Backends & export

| Backend | Best for | Dependency |
| :--- | :--- | :--- |
| **SVG** | Lightweight static views and portable vector output | None for core operations |
| **Plotly** | Interactive hover, selection, 3D WebGL, camera and playback controls | `plotly` |
| **Matplotlib** | Conventional static plots and PNG output | `matplotlib` |

```python
view = sd.see(model, input=x, view="3d")
view.save("network.html")               # Recommended for interactive 3D sharing

# For static SVG with no interactive Plotly requirement:
sd.see([1, 4, 9, 16], backend="svg").save("sequence.svg")
```

PNG export capabilities depend on the chosen backend; Python-side raster export of genuine 3D scenes may require Plotly's optional Kaleido integration.

## ⚙️ Design limits, by intention

SeeDL is designed to stay responsive and avoid misleading diagrams.

- The detailed neuron graph supports built-in `nn.Linear`/`nn.Sequential` patterns and documented elementwise activations. Unsupported structures receive a disclosed architecture view.
- Default limits are **100 total neurons**, **48 neurons per layer**, **12 layers** and **1,500 rendered connections**. Sampling and filtering are disclosed in the visualization.
- Neuron-selection menus are optimized for compact networks. Very large networks prioritize readability and reduced browser payloads.
- Layout coordinates in 3D show network structure; they are **not learned neuron embeddings**.
- Animation highlights the order of **captured computation states**; it is not a simulation of particles moving through a neural circuit.
- GPU, all browser/WebGL variants, and every notebook frontend have not been verified. See the [visual acceptance record](docs/VISUAL_ACCEPTANCE.md).
